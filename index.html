Chromebook Pixel 2013 Lightbar Switch
发表于2017-01-06|技术
Chromebook Pixel 2013 顶盖上有一条灯带（lightbar），开机、充电、干活的时候都会一闪一闪，设计感是有了，但晚上在暗处用电脑的时候真的挺刺眼。找了一下发现这条灯带其实是可以手动开关的，记录一下方法。 进入开发者模式之后，在 crosh（Ctrl+Alt+T 打开 Crosh，输入 shell 进入 Linux shell）里可以直接用 ectool 控制灯带： 12sudo ectool lightbar off # 关闭灯带sudo ectool lightbar on # 恢复默认显示 如果只是想在开会、看电影这种场合临时关一下，用这条命令比每次都进系统设置里翻半天方便多了。缺点是重启之后会恢复默认状态，想要开机自动关闭的话，得把这条命令写进启动脚本里。
Audi B6 A4 刹车液报警：只在冷天出现
发表于2016-12-08|汽车
冬天一冷，车就开始出毛病。这次是刹车系统报警——嘀嘀响、手刹灯闪三下——但只在天冷的时候出现，暖和了就正常，运气不好还会持续报个不停。上网一查，发现不少车友都遇到过同样的问题。 翻了一圈车友论坛，大家给出的可能原因主要集中在这几个方向： 卡钳泄漏：某个卡钳的放气阀（bleeder screw）密封不好，转弯时因为离心力，刹车液被甩到某一侧导致液位报警，换掉那个卡钳就能解决。 传感器故障：也有车友是每次启动车子就报警、开起来却完全正常，怀疑是液位传感器接触不良，跟真实液位没关系。 和 ESP 联动：ABS/ESP 属于同一套系统，如果 ESP 故障灯也一起亮，说明可能是 ALB 模块或传感器的问题，建议用 VAG-COM 读一下故障码，能更精确定位问题出在哪。 对我来说，因为刹车片、刹车盘、刹车液这些部件本来就快到了该换的里程，所以没有再深挖具体故障点，先把这件事放一放。 更新：后来确认就是刹车片磨损导致刹车液面下降，触发了报警。冲洗了整套刹车系统、换上新液体之后，报警就再也没出现过。

被入侵之后：一次意外的DDoS脚本
发表于2016-11-26|技术
网站在我还没做好安全措施的时候就被黑客入侵了，密码被改，还被拿这台主机当肉鸡对其他网站发起了 DDoS 攻击，说起来还挺有意思的一次经历。 黑客留下的脚本叫 HttpDoser，用法很简单：python HttpDoser.py 目标网站。出于好奇，我在自己另一个网站 rednik.pw 上试了一下，跑完之后网站直接打不开了——效果是真实的。 脚本本身没什么复杂逻辑：伪造大量带随机参数的 HTTP 请求、配上一批伪造的 User-Agent 和 Referer，开几百个线程同时打过去，把目标服务器的连接和带宽都占满。这类脚本网上并不难找，攻击原理也没什么新意，就不贴完整代码了。 事后复盘，被入侵这件事本身不道德归不道德，但根源还是在自己：用了弱口令。后来改了新密码，之后也打算换成密钥登录，从根上堵住这个漏洞。
